# KMM Tax Group

A finished, self-contained static website for **KMM Tax Group**, a multi-division tax firm.

The entire site lives in a single `index.html` file — all markup, CSS, and JavaScript are inline, with fonts loaded from Google Fonts. There is **no build step**, bundler, or dependencies to install.

## Divisions

The site presents the firm's three divisions, each on its own hash-routed page:

- **Klein Muskat** — personal income tax, trusts, and estates
- **Klein Mirsky** — business tax and year-round bookkeeping
- **Klein Real Estate** — tax work for investors, partnerships, and property entities

It also includes a home overview and a contact page with an inquiry form.

## Viewing the site

Just open `index.html` in any modern web browser — double-click the file, or drag it into a browser window. No server or build step is required.

## Notes

A few items are intentionally left as placeholders to be filled in before launch (shown in the site as bracketed text), including the firm phone number, email, and office address, and the Klein Real Estate client-login URL.
